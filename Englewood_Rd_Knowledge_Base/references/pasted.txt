Wirsbo proMix 201

Description from Supply House: https://www.supplyhouse.com/Wirsbo-Uponor-A3040201-proMIX-201-Single-temperature-Injection-Mixing-Control-3827000-p 
	The proMIX 201 is a weather responsive mixing control that offers single temperature reset using variable speed injection mixing. The proMIX 201 mixes one supply temperature for radiant floor heating, while simultaneoulsy protecting the boiler fro low return water temperatures. It uses a boiler enable signal to fire the boiler and to enable the primary pump. The proMIX 201 is also used in setpoint mode where the control maintains a constant supply water temperature.
